# 用户逻辑表结构

## 1. 使用原则

用户在查询界面中只使用本文档中的逻辑表名，不需要知道数据实际位于主节点还是三个数据分节点。

例如用户应写：

```sql
SELECT borrow_id, reader_id, book_id, borrow_status
FROM borrow_record
WHERE reader_id = 110000000001;
```

而不是：

```sql
SELECT * FROM borrow_record_fragment;
```

主节点后端负责将逻辑表改写成物理表、选择站点、发送命令并合并结果。

## 2. 逻辑表与物理表映射

| 用户逻辑表 | 物理表 | 存储位置 |

| `site` | `site_node` | 主节点 |

| `campus` | `campus` | 主节点 |
| `category` | `category` | 主节点 |
| `book` | `book_catalog` | 主节点 |
| `library` | `library_fragment` | Site 1、Site 2、Site 3 水平分片 |
| `reader` | `reader_fragment` | Site 1、Site 2、Site 3 水平分片 |
| `book_copy` | `book_copy_fragment` | Site 1、Site 2、Site 3 水平分片 |
| `borrow_record` | `borrow_record_fragment` | Site 1、Site 2、Site 3 水平分片 |

## 12. 当前支持的 SQL 范围

查询支持：

```text
SELECT、FROM、WHERE、AND、OR
=、<>、>、>=、<、<=、LIKE、IN
同类数据库内的 INNER JOIN 和 LEFT JOIN
ORDER BY、LIMIT
COUNT、SUM、MIN、MAX
```

写入支持：

```text
对 library、reader、book_copy、borrow_record 执行受控的
INSERT、UPDATE、DELETE
```

写操作由后端解析为结构化请求，再生成参数化 SQL 并路由；不把输入 SQL 原样交给数据库。只有 `ADMIN` 可以通过 SQL 工作台写入，管理页面的结构化 CRUD 另按角色限制站点范围。

限制：

- 一次只能执行一条语句；
- 不允许 `DROP`、`ALTER`、`CREATE`、`TRUNCATE`；
- `INSERT` 仅支持显式字段的单行 `VALUES`；
- `UPDATE` 和 `DELETE` 必须使用主键单值等值条件；
- 不支持子查询、CTE、UNION 和 OFFSET；
- 主节点逻辑表与分片逻辑表暂不能在同一条 SQL 中直接 JOIN；
- 广播聚合暂不支持 `AVG`、`DISTINCT`、`GROUP BY` 和 `HAVING`；
- 单次最多返回 500 行，超过的 `LIMIT` 会被自动限制；
- `reader.password_hash` 不对用户开放。

## 13. 查询示例

查询书目：

```sql
SELECT book_id, title, author
FROM book
WHERE title LIKE '%数据库%'
ORDER BY book_id;
```

根据读者编号精确路由：

```sql
SELECT borrow_id, reader_id, book_id, due_time, borrow_status
FROM borrow_record
WHERE reader_id = 110000000001;
```

根据校区路由：

```sql
SELECT library_id, library_name, status
FROM library
WHERE campus_id = 1009;
```

广播查询并合并：

```sql
SELECT copy_id, book_id, copy_status
FROM book_copy
WHERE copy_status = 'AVAILABLE'
ORDER BY copy_id
LIMIT 20;
```

主节点内连接：

```sql
SELECT b.book_id, b.title, c.category_name
FROM book AS b
JOIN category AS c ON c.category_id = b.category_id
ORDER BY b.book_id;
```

统计三个站点的可借馆藏：

```sql
SELECT COUNT(*) AS available_count
FROM book_copy
WHERE copy_status = 'AVAILABLE';
```
