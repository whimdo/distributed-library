# 用户角色与权限

系统采用统一登录入口，登录成功后由前端路由和后端接口共同执行权限控制。前端隐藏无权入口，后端依据访问令牌再次校验，不能通过手工修改 URL 或 `site_id` 绕过。

| 功能 | STUDENT | SITE_ADMIN | ADMIN |
|---|---:|---:|---:|
| 全网书目检索 | ✓ | — | — |
| 附近图书馆与距离查询 | ✓ | — | — |
| 查看本人借阅 | ✓ | — | — |
| 查看本站读者、馆藏、借阅 | — | ✓ | ✓ |
| 修改本站读者状态和跨校权限 | — | ✓ | ✓ |
| 修改本站馆藏状态和跨校借阅标志 | — | ✓ | ✓ |
| 查看本站 GIS 图层和节点命令 | — | ✓ | ✓ |
| 切换和管理任意站点 | — | — | ✓ |
| 使用分布式 SQL 工作台 | — | — | ✓ |
| 查看全局逻辑表结构 | — | — | ✓ |

## 数据范围规则

- `SITE_ADMIN` 的 `managed_site_id` 由主节点账号表保存，接口不信任前端提交的站点范围。
- 站点管理员不传 `site_id` 时，后端自动使用其 `managed_site_id`；提交其他站点编号时返回 HTTP 403。
- `ADMIN` 可以不传 `site_id` 查询全部三个数据站点，也可以选择单个站点。
- `STUDENT` 的借阅查询固定使用令牌中的 `reader_id` 和 `home_site_id`，不接受前端指定其他读者。
